## Cloudflare
1. Создайте **новый** Worker, не используйте старые URL.
2. Вставьте `worker.js` и добавьте Workers AI binding с именем `AI` (или используйте `wrangler.toml`).
3. Задайте переменную `ALLOWED_ORIGIN` = `https://YOUR_USERNAME.github.io` (без пути репозитория, без конечного слеша).
4. Опубликуйте Worker. Скопируйте фактический URL вида `https://...workers.dev`.
5. В `ai.js` **один раз** замените `ЖАҢА_CLOUDFLARE_WORKER_URL` реальным URL Worker без `/api/chat`.
6. Проверьте запрос из опубликованного сайта. API key в браузере не нужен: вызов модели происходит внутри Worker через binding `AI`.

## GitHub Pages
Загрузите содержимое этой папки в корень нового репозитория. Settings → Pages → Deploy from a branch → main / root. Дождитесь публикации. `file://` и локальный просмотр могут не поддерживать модули и CORS: тестируйте на Pages.

## ВАЖНО: ограничения безопасности
**Это публичный демонстрационный прототип.** `localStorage` не синхронизируется между устройствами, коды У01–У11 НЕ являются аутентификацией, учительский кабинет НЕ защищён. Не размещайте реальные работы детей, персональные данные или конфиденциальные фрагменты. Для реального использования нужны серверная аутентификация, разграничение ролей, согласия и база Cloudflare D1. Нельзя обеспечить безопасность только скрытием кнопок в статическом GitHub Pages.

**Проверка модели**: модель `@cf/meta/llama-3.1-8b-instruct` использует Workers AI, доступность и бесплатные лимиты проверяйте в актуальной панели Cloudflare. Без нового Worker и его URL AI не заработает. Результаты диагностики пусты до ручного ввода; не выдавайте демонстрационные данные за апробацию.


## ULTRA дополнения
- `dashboard.html`: персональный маршрут, достижения, критерии и реальные оценки без подмены данных.
- `studio.html`: интерактивный навигатор эмоций, сравнение позиций, альтернативные решения и рефлексия.
- `backup.js`: экспорт/импорт обезличенного класса в JSON. Импорт заменяет локальные данные после подтверждения.
- Прототип НЕ синхронизирует устройства: для настоящего класса нужен D1 + серверная авторизация.
- AI включится только после создания нового Worker, установки AI binding, ALLOWED_ORIGIN и ввода реального URL в ai.js.
- Ученикам нельзя передавать реальные ФИО и иные персональные сведения в AI.
